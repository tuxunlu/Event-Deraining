EvORSP master table

Every number the campaign has actually measured, with its provenance and its caveats. Event-DA on test unless stated. Anything still running is marked, not estimated.

How to read this Event-DA is balanced accuracy over individual events — 0.5·(kept background / all background + dropped rain / all rain), per frame, frame-averaged, with one global threshold picked on val. It is not pixel-DA and the two are not interchangeable. Seed range differs enormously by dataset: ±0.0026 on KITTI, up to ±0.0304 on SPAC, unmeasured on real. Differences smaller than the relevant seed range are not claims.

Inter-window context — how much, and how arranged

KITTI · control is 2 windows × 1 pooled slice

Context windows were max-pooled to one occupancy plane per polarity, discarding when a pixel fired inside them. --ctxres K keeps K time slices instead; K=1 was verified elementwise to equal the max over K=4's slices, so the control is nested inside every arm and the arms can only add information.

Null — and the interesting part is why Best arm is +0.0010 against ±0.0026. But val rises monotonically with context information (0.9503 → 0.9513 → 0.9516 → 0.9525) while test stays flat. The model demonstrably uses the extra context; it buys fit on the val intensities (20/80 mm) that does not transfer to test (50/150 mm). That is a generalization gap, and it explains the whole run of null architecture results better than “the trunk has enough capacity”.

The retention guarantee — and what it costs

We claimed the ungated persistent band meant the network cannot delete the static scene. Attacked directly, that is false. The bounded-correction trunk logit = α·res + C·tanh(z/C) makes it true, since the second term is confined to (−C, +C) and so logit > α − C for any weights.
